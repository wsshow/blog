## 引子：打仗之前，先把话说绝

前面几篇拆的，都是汉魏南北朝的檄文。这一篇要追源头——追到公元前 578 年，春秋。

这年夏天，晋国大夫吕相出使秦国，当着秦桓公的面宣读了一篇“绝交辞”：把秦晋两国近百年的交往史从头到尾盘点一遍，谁对谁错、谁欠谁还，一笔一笔地算；算到最后，结论是“错全在你，我被迫应战”。读完不久，晋国就率诸侯之师与秦国打了一场麻隧之战。

这篇辞令的文学身份，是刘勰给的。《文心雕龙·檄移》里有一段“文体考古”：

> 齐桓征楚，诘苞茅之阙；晋厉伐秦，责箕郜之焚。管仲吕相，奉辞先路，详其意义，即今之檄文。

——齐桓公伐楚，拿“包茅不贡”当由头；晋厉公伐秦，先责问“焚我箕郜”。管仲和吕相这些人，出兵之前先把话讲在前面，**按意义说，这就是今天的檄文**。

也就是说：从吕相这篇辞令起，“先定基调、再列罪状、最后给出路”的三段式就定型了——陈琳、骆宾王的檄文里那些熟悉的配方，源头在这里。这一篇，算是这个系列的“史前篇”。

## 一、前史：秦晋之好是怎么变坏的

### 1.1 一场持续百年的豪门恩怨

“秦晋之好”这个成语，说的就是春秋前期秦晋两国的联姻：秦穆公娶了晋献公的女儿；此后穆公又先后扶立晋惠公、晋文公——**恩情是真的，恩怨也是真的。**

梳理一遍这条关系线（大致按《左传》记载）：

| 时间（前） | 事件 |
| --- | --- |
| 约 656 | 秦穆公娶晋献公之女，“秦晋之好”开局 |
| 645 | 韩原之战：秦穆公伐晋，俘晋惠公，随后放归 |
| 636 | 秦穆公派兵护送晋文公回国即位 |
| 630 | 秦晋联合围郑；秦国背着晋国独与郑国结盟（“秦大夫不询于我寡君，擅及郑盟”） |
| 627 | 殽之战：秦军越晋境袭郑不成，归途被晋襄公伏击，全军覆没 |
| 620 | 令狐之役：秦康公送公子雍入晋争位，被晋军击败 |
| 615 | 河曲之战：秦康公再次伐晋，战于河曲 |
| 594 | 辅氏之役：秦桓公趁晋有狄难攻晋，被魏颗击败 |
| 580 | 令狐之会：秦伯不肯渡河会盟，随后背盟，又挑拨白狄与楚国 |
| 578 | 吕相绝秦；同年麻隧之战，秦师败绩 |

注意两个坐标：**殽之战（627）**是全面翻脸的起点；**令狐之会（580）之后秦国的背盟与挑拨**，是这篇辞令的直接导火索。

### 1.2 吕相是谁，绝秦是什么意思

吕相，晋国大夫（杜预注认为他是魏锜之子，食邑在吕，故称吕相）。他这次出使，不是寻常外交——“绝”是断绝关系，**先绝交、后开战，是春秋的战争程序**：得先把道理讲绝，仗才打得“有名”。

而这篇辞令的特殊之处在于：它不是谈判，是“通知书”。吕相代表晋厉公来宣读完、传达完，任务就完成了——**他说的每一句话，都是说给第三方（诸侯）和后世听的。**

## 二、原文全文

> **《吕相绝秦》** ｜ 《左传·成公十三年》 ｜ 前 578 年
>
> 夏，四月戊午，晋侯使吕相绝秦，曰：
>
> 昔逮我献公及穆公相好，戮力同心，申之以盟誓，重之以昏姻。天祸晋国，文公如齐，惠公如秦。无禄，献公即世，穆公不忘旧德，俾我惠公，用能奉祀于晋；又不能成大勋，而为韩之师。亦悔于厥心，用集我文公，是穆之成也。文公躬擐甲胄，跋履山川，逾越险阻，征东之诸侯，虞夏商周之胤而朝诸秦，则亦既报旧德矣。
>
> 郑人怒君之疆埸，我文公帅诸侯及秦围郑。秦大夫不询于我寡君，擅及郑盟，诸侯疾之，将致命于秦。文公恐惧，绥靖诸侯。秦师克还无害，则是我有大造于西也。
>
> 无禄，文公即世。穆不为吊，蔑死我君，寡我襄公，迭我殽地，奸绝我好，伐我保城，殄灭我费滑，散离我兄弟，挠乱我同盟，倾覆我国家。我襄公未忘君之旧勋，而惧社稷之陨，是以有殽之师。犹愿赦罪于穆公，穆公弗听，而即楚谋我。天诱其衷，成王陨命，穆公是以不克逞志于我。
>
> 穆襄即世，康灵即位。康公，我之自出，又欲阙翦我公室，倾覆我社稷，帅我蝥贼，以来荡摇我边疆，我是以有令狐之役。康犹不悛，入我河曲，伐我涑川，俘我王官，翦我羁马，我是以有河曲之战。东道之不通，则是康公绝我好也。
>
> 及君之嗣也，我君景公引领西望，曰：“庶抚我乎？”君亦不惠称盟，利吾有狄难，入我河县，焚我箕郜，芟夷我农功，虔刘我边陲，我是以有辅氏之聚。君亦悔祸之延，而欲徼福于先君献穆，使伯车来命我景公，曰：“吾与女同好弃恶，复修旧德，以追念前勋。”言誓未就，景公即世，我寡君是以有令狐之会。君又不祥，背弃盟誓；白狄及君同州，君之仇雠，而我之昏姻也。君来赐命曰：“吾与女伐狄！”寡君不敢顾昏姻，畏君之威，而受命于使。君有二心于狄，曰：“晋将伐女。”狄应且憎，是用告我。楚人恶君之二三其德也，亦来告我曰：“秦背令狐之盟，而来求盟于我。昭告昊天上帝，秦三公，楚三王，曰：‘余虽与晋出入，余唯利是视。’不谷恶其无成德，是用宣之，以惩不壹。”诸侯备闻此言，斯是用痛心疾首，昵就寡人。
>
> 寡人帅以听命，唯好是求。君若惠顾诸侯，矜哀寡人，而赐之盟，则寡人之愿也。其承宁诸侯以退，岂敢徼乱？君若不施大惠，寡人不佞，其不能以诸侯退矣。敢尽布之执事，俾执事实图利之！

**版本说明：** 本篇取自《左传·成公十三年》，《古文观止》卷二收录，文字从通行本。文中“君”指秦桓公，“我寡君”“寡人”则指晋厉公——全篇是吕相代表晋国对秦国说的话；末尾的“敢尽布之执事，俾执事实图利之”是春秋辞令的标准收束语，意为“该说的都说了，请您自己掂量利害”。

## 三、逐段赏析

### 3.1 结构：一篇“话术教科书”

全篇按时间顺序推进，每一段都执行同一个动作：**先说我方曾经多好，再说你方如何辜负。**

1. **蜜月期（献公—穆公）**：“戮力同心，申之以盟誓，重之以昏姻。”——婚也结了，誓也盟了。
2. **文公时期**：“秦师克还无害，则是我有大造于西也。”——围郑的时候你们秦军背着我们跟郑国私自结盟，诸侯都怒了要打你，是我们文公压下了这事，让你安然回国。**这是“我于你有大恩”。**
3. **穆公时期**：“蔑死我君，寡我襄公，迭我殽地，奸绝我好，伐我保城，殄灭我费滑，散离我兄弟，挠乱我同盟，倾覆我国家。”——文公刚死，秦国不吊丧，看轻我们新君，犯我殽地，断绝邦交，攻打城邑，灭我费滑……**这是“你于我有大罪”。**
4. **康公时期**：“康公，我之自出。”——康公的母亲是晋国女子（“我之自出”），自家外甥，却“欲阙翦我公室”，令狐、河曲两次用兵。
5. **桓公时期（当下）**：令狐之会秦伯不肯渡河，盟誓未成就背弃；还两面挑拨白狄和楚国。**这是压垮关系的最后一根稻草。**

结构本身的杀伤力在于时间线：**七十多年的账，一笔一笔念，读者（诸侯）跟着一路听下来，会自然得出结论“秦负晋”。** 至于被“省略”的晋方过失——比如令狐之役的起因是晋国自己先毁约，辞令里是不会出现的。

### 3.2 语言：动词排比与成语的源头

全篇最漂亮的一句，是声讨秦穆公的那串排比：

> 蔑死我君，寡我襄公，迭我殽地，奸绝我好，伐我保城，殄灭我费滑，散离我兄弟，挠乱我同盟，倾覆我国家。

“蔑、寡、迭、奸、伐、殄、散、挠、覆”九个动词连发，节节升高，最后落在“倾覆我国家”。**这是中国最早的“动词控诉法”**——不需要形容词，一串动词就是最大的愤怒。后世檄文那些四字句连发的气势，源头在这里。

顺便统计两个语言遗产：

- “**戮力同心**”——“戮力同心，申之以盟誓”；
- “**痛心疾首**”——“诸侯备闻此言，斯是用痛心疾首”。

两个今天仍在用的成语，都在这篇辞令里。

而全篇收尾，是全中国最早的“最后通牒”之一：

> 君若不施大惠，寡人不佞，其不能以诸侯退矣。敢尽布之执事，俾执事实图利之！

——你要是还讲情面，我们就坐下来盟誓；你要是连这点面子都不给，那我带着诸侯们的军队，就没法退回去了。**最后一句“俾执事实图利之”，字面上是“请您为自己盘算盘算”，实际上是：刀已经架上了，你自己选。**

### 3.3 史实核查：吕相的话有几分真

对照《左传》前文，可以逐条检验。有意思的是——**大部分都不是凭空捏造，而是“选择性叙述”：**

- “申之以盟誓，重之以昏姻”——真的（秦穆公娶晋女）；
- “秦大夫不询于我寡君，擅及郑盟”——真的（烛之武退秦师，秦私与郑盟）；
- “殄灭我费滑”——真的（秦军灭滑还师，才中了殽之伏击）；
- “康公，我之自出”——真的（秦康公是晋女所生）；
- 但**令狐之役的起因**——晋襄公死后，晋国先答应了迎立秦国护送的公子雍，随后反悔发兵袭击——被辞令处理成了秦国的单方面“欲阙翦我公室”；
- 至于把殽之战说成“我襄公……是以有殽之师”（被迫自卫），更是典型的“我方视角”：真实情况是秦军越境偷袭郑国未成，晋国选择在殽山打埋伏。

**同一段历史，换个立场就是另一篇《绝晋》。** 这不是说吕相说谎——在外交辞令里，选择讲哪些事实、怎么排因果，本身就是“话术”。读它的时候，正好可以把《讨曹操檄》里学到的尺子拿出来再用一次：**欣赏它的气势，同时把它当“一方叙事”看。**

### 3.4 从辞令到檄文：基因是怎么传的

刘勰说“管仲吕相，奉辞先路……即今之檄文”，这不是文学史家的客气话——后世的檄文里，能直接找到这篇的“基因片断”:

- 陈琳《讨曹操檄》里那句“**幕府无德于兖土之民，而有大造于操也**”——“有大造于”这种句式，就是抄的吕相（“则是我有大造于西也”）。这不是巧合：李善注《文选》时，特地在这句下面引了《左传》吕相绝秦，等于替我们做了注释；
- “先叙旧情、再列罪状、最后通牒”的三段式，成为后来一切讨伐文的标准结构——骆宾王檄里的“一抔之土未干”，丘迟信里的“若遂不改，方思仆言”，都是这篇辞令的远房后代。

**当众宣读、陈述罪状、申明立场、给出最后机会**——这一整套“讨伐文体”的章程，是在前 578 年这场绝交里成形的。

## 四、后事：绝交之后

辞令宣读完毕，战争随即落地。同年夏天（《左传》记在五月），晋厉公率齐、鲁、宋、卫、郑等诸侯之师与秦军战于麻隧（约在今陕西泾阳一带），秦师败绩。此后秦国在相当长一段时间里被排斥在中原事务之外——**一句话启动一场战争，晋国的舆论准备可谓成功。**

但历史还有下文：麻隧之战并没有终结秦晋的恩怨。此后两国继续纠缠了几十年，直到春秋格局彻底翻篇。更值得玩味的是记忆的筛选：

- 麻隧之战，除了专业读史的人，今天还有谁记得？
- 而吕相这篇“绝交辞”进了《古文观止》，两千六百年后还在被逐句赏析。

**打仗的赢了战役，写文章的赢了时间。** 这个规律，从吕相到陈琳、骆宾王、丘迟，一路没变过。

## 五、结语：一切讨伐文书的起点

把这四篇连起来看，正好是一条文体的进化链：

- **《吕相绝秦》**：春秋辞令。外交官当众宣读，定基调、列罪状、下通牒——檄文的史前形态。
- **《讨曹操檄》**：汉末骈檄。有了公开传播的媒介（“传檄州郡”），骂人技艺拉满。
- **《讨武曌檄》**：初唐骈檄。修辞与人心计算的巅峰。
- **《与陈伯之书》**：劝降书。证明不骂人也可以赢。

而《北山移文》站在旁边，提醒我们这套文体还有幽默与刻薄的一面。

两千六百年过去，吕相的那句“俾执事实图利之”仍然是外交辞令的标准腔调：**话说得越客气，意味越不客气。** 这大概就是语言最古老、也最稳定的力量。
